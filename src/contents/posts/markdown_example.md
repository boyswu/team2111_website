# 一级标题

段落之间用一个空行分隔。

第二段。_斜体_、**加粗** 和 `等宽字体`。项目符号列表如下：

- 这个
- 那个
- 另一个

注意 —— 不考虑星号 —— 实际的文本内容从第 4 列开始。

> 引用是这样写的。  
>  
> 它们可以跨多个段落，  
> 如果你愿意的话。

使用 3 个短横线表示破折号。使用 2 个短横线表示范围（例如，“在第 12--14 章中”）。三个点 ... 会被转换成省略号。支持 Unicode。☺

## 二级标题

这是一个编号列表：

1. 第一项
2. 第二项
3. 第三项

再提醒一下，实际文本从第 4 列开始。这里有一个代码示例：

    # 重申一下 ...
    for i in 1 .. 10 { do-something(i) }

如你所料，缩进 4 个空格。顺便说一下，你也可以使用分隔代码块：

```
define foobar() {
    print "欢迎来到风味之国！";
}
```

这让复制粘贴更容易。你还可以为代码块指定语言高亮：

```python
import time
# 快速数到十！
for i in range(10):
    # 但不要太快
    time.sleep(0.5)
    print(i)
```

### 三级标题

嵌套列表：

1. 首先，准备这些食材：

   - 胡萝卜
   - 芹菜
   - 扁豆

2. 煮一些水。

3. 把所有东西倒进锅里并按以下步骤操作：

        找到木勺
        打开锅盖
        搅拌
        盖上锅盖
        把木勺横放在锅柄上
        等待 10 分钟
        回到第一步（或关火结束）

   不要碰木勺，否则它会掉下来。
